# Noesis 排版与笔记插件设计

## 目标

改善全站阅读排版，修复 Markdown 结构导致的断行、列表与公式间距问题；不改变笔记表达的任何内容。

## 范围

- 在 `assets/css/noesis.css` 统一调整段落、标题、列表、引用、公式、代码块、表格和图片的阅读间距与窄屏表现。
- 只修复 `content/` 中的空行、列表标记、缩进和显式换行等 Markdown 结构。不得修改正文文字、公式源码、代码、链接目标、图片地址或 frontmatter 值。
- 启用 docmd 内置的 `mermaid` 与 `git` 插件，分别支持 Markdown 图表和笔记更新时间。

## 非目标

- 不新增 PWA、评论、分析或语义搜索依赖。
- 不添加新内容、callout、课程目录页或手写导航。
- 不改变自动生成的可展开侧栏课程树。

## 验证

运行 `npm run build` 与 `npm run check`；检查 Markdown 差异仅包含格式字符，并抽样查看数学、代码、表格和列表页面的生成结果。
