# 知识库深色主题设计

## 目标

将知识库的深色阅读界面收敛到主站 `cavill.site` 的配色，同时保留现有布局、数学渲染、代码高亮和内容。

## 实现

仅扩展 `assets/css/blockquote.css`：在深色主题媒体查询中覆盖 docmd 的既有主题变量，并让正文链接始终显示灰色下划线。

| 元素 | 颜色 |
| --- | --- |
| 页面背景 | `#191919` |
| 正文 | `#e6e6e6` |
| 边框 | `#373737` |
| 链接 | `#d4d4d4` |
| 链接悬停 | `#ffffff` |

不修改浅色主题，不增加依赖，也不改动生成器默认样式。

## 验证

运行 `npm run build`，确认生成成功且自定义样式被复制到站点输出目录。
