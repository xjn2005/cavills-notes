# Noesis 站点完善设计

## 目标

把 Noesis 收敛为简洁、易读、易维护的中文学习型知识库，并清除 Quartz 迁移后的遗留信息。

## 范围

### 视觉

- 保持 docmd 的现有导航结构，以 Apple Notes 式阅读界面替换默认视觉语言。
- 使用系统字体、低对比浅灰背景、半透明侧栏和单一系统蓝色强调；不添加依赖、不替换模板。
- 调整正文宽度、留白、标题、链接、代码块、提示框与移动端间距，去除悬浮卡片和重阴影。
- 首页使用简洁的大标题与课程列表，并兼容深浅色模式。

### 学习体验

- 将 docmd 系统界面切换为中文，保留根路径和现有内容目录。
- 配置明确的侧栏导航与 Lucide 图标，取代自动生成的扁平目录。
- 为首页和三门课程补充课程定位、学习路径和笔记入口；不改动笔记正文。
- 为现有 callout 增加统一的中文标题和 Lucide 图标：说明、提示、注意、警告和完成分别使用语义匹配的图标。
- 使用现有的搜索、目录、上一页/下一页、代码复制；移除页面级 Copy Context 等不属于个人阅读流程的工具。
- 只在确有内容层级需要时使用折叠区块、步骤和状态标签，保持 Markdown 可维护。

### 内容与维护

- 重写首页，使用简短站点介绍和三个课程入口，移除“正在建设”和旧平台表述。
- 更新 README：改为 docmd、当前站点地址和实际本地工作流。
- 更新仅本地保存的 `LOCAL_MAINTENANCE.md`：Obsidian 同步、预览、构建检查与 GitHub Pages 发布步骤。

## 不做

- 不添加评论、统计、PWA、搜索替换、模板系统或新依赖。
- 不改动已有笔记正文与目录结构。
- 不把 `LOCAL_MAINTENANCE.md` 提交到 GitHub。
- 不添加双链图谱、账号、数据库或自定义后端。

## 验证

- `npm test`
- `npm run build`
- `npm run check`
