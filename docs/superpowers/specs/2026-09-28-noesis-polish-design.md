# Noesis 站点完善设计

## 目标

把 Noesis 收敛为简洁、易读、易维护的中文个人知识库，并清除 Quartz 迁移后的遗留信息。

## 范围

### 视觉

- 保持 docmd 的 Sky 主题与现有导航结构。
- 新增一份小型自定义 CSS，不添加依赖、不替换模板。
- 调整正文宽度、留白、标题、链接、代码块、提示框与移动端间距。
- 为首页入口提供轻量卡片式呈现，并兼容深浅色模式。

### 内容与维护

- 重写首页，使用简短站点介绍和三个课程入口，移除“正在建设”和旧平台表述。
- 更新 README：改为 docmd、当前站点地址和实际本地工作流。
- 更新仅本地保存的 `LOCAL_MAINTENANCE.md`：Obsidian 同步、预览、构建检查与 GitHub Pages 发布步骤。

## 不做

- 不添加评论、统计、PWA、搜索替换、模板系统或新依赖。
- 不改动已有笔记正文与目录结构。
- 不把 `LOCAL_MAINTENANCE.md` 提交到 GitHub。

## 验证

- `npm test`
- `npm run build`
- `npm run check`
